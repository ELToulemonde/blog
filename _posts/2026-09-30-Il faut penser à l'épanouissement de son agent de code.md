## L'épanouissement de son agent de code

Si vous déléguez tout votre code à un agent, est-ce que vous vous êtes assuré qu’il s’épanouisse dans son projet ?

Un développeur attentionné veillera à sa Developer Experience pour maintenir sa productivité, même quand les fonctionnalités s’accumulent.

Alors pourquoi ne pas faire pareil avec vos agents ?

Il faut désormais demander à un agent de travailler sur son Agent Experience. 🤖

Un peu provocatrice, cette idée vise à sensibliser à l'importence d'envisager la contribution de l'agent sur le long terme, et donc le forcer à soigner son expérience de développement pour qu'il reste productif.
